To begin, open the Adobe XD application. The main menu is located at the top of the screen and includes options for File, Edit, View, Object, and Help. Each menu contains various commands and functions essential for designing and prototyping. For instance, under the File menu, you can find options to create new projects, open existing ones, and save your work.

The toolbar on the left side of the screen provides quick access to commonly used tools such as the Selection Tool, Rectangle Tool, and Text Tool. Each tool has specific functions that can be explored further in the respective sections of this guide.
