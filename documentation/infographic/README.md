# Infographic

A small set of static pages showing how the redactor works: a cover with the five stages, and a page for each stage. The box numbers (1.1 to 6.6) match [Application-Flow.md](../Application-Flow.md), so notes can refer to either.

Open `index.html` in a browser. There is nothing to build or install: the pages are plain HTML and one stylesheet, and they follow the system light or dark setting.

| Page | Contents |
|---|---|
| `index.html` | Cover: the five stages |
| `1-input.html` to `5-write.html` | One page per stage |
| `6-positions.html` | Extra: how positions are found |
